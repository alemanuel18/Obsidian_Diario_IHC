# Rediseño
<p align="justify">Al abrir la aplicación lo primero que se mostrara será el For You, donde se mostraran las historias y lives de las cuentas que siga el usuario además de un real de su algoritmo, amigos o de las personas que sigue. De esta manera el usuario no se perdería de las historias que suben las personas a las que sigue y sigue viendo contenido al entrar en la app, además cuando el usuario lo desee visualizar mas contenido, bastara con un swipe de abajo hacia arriba para ocultar el apartado de las historias.</p>

![[Página 1.png]] 

<p align="justify">En este rediseño solo existe una pestaña para ver reals, en ves de tres apartados para ver contenido como en la aplicación original (For You, Following, Explore y Friends). De esta manera se pueden reutilizar estos espacios para acciones mas importantes como la de Crear más contenido y acceder al apartado de mensajes desde la pantalla principal, con simple swipe. En vez de tener tres pantallas que cumplen con la misma función.</p>



<p align="justify">Esta es la vista de la aplicación cuando el panel de historias y lives se contrae, al cual se puede seguir accediendo mediante al botón semitransparente que se encuentra debajo del apartado de For You, el cual a su vez indica si existen nuevas historias o lives.</p>

![[Página 2.png]]

<p align="justify">La barra inferior también fue rediseñada, ya que se puede acceder al apartado de mensajería y creación de contenido con simple swipe, seria redundante el tener botones en la parte inferior para eso. Por lo que se reubicaron apartados que se encontraban en la parte superior (Search y Live) para acceder a ellos de manera más sencilla.</p>

# Revisión del diseño (Parte 1)
- ¿Qué problemas específicos busca resolver mi diseño?
La redundancia que existía para ver contenido, siendo que existían tres apartados dedicado a lo mismo y mejorar el acceso a apartados como la creación de contenido y mensajería. 
- ¿Mi diseño refleja adecuadamente la esencia y funcionalidad actual de TikTok?
Si, ya no eliminamos las funciones principales que permiten la conectar con personas, solo se modifico la forma de acceso y/o se unificaron en una sola. 
- ¿Son los elementos visuales del tamaño adecuado para su prioridad?
Si, ya que los botones agregados a la barra inferior cuentan con las misma dimensiones que los que permanecieron, además las funciones de creación y comunicación son accesibles con un swipe. 
- ¿Cómo podría mi diseño mejorar la experiencia para diferentes tipos de usuarios (nuevos, frecuentes, influencers)?
Para los nuevos, al simplificar las pantallas de contenido a solo una, eso evita que se sientan agobiados con diferentes apartados que cumplen con la misma función. 
Frecuentes, estos al encontrarse con una interfaz renovada la cual se centra más en conectar con personas, que en mostrar contenido de tres maneras distintas. 
Para influencers, al facilitar el acceso al apartado de creación de contenido con un swipe, les facilita el crear contenido con una sola mano.
- ¿Hay elementos que aún puedan simplificarse o eliminarse sin perder funcionalidad?
El apartado con el cual interactúas con el con el contenido (cerrazón, comentario, guardar, resubir, perfil del creador, descripción y pista musical) no fue modificado, es posible que se pueda modificar ese apartado para despejar la interfaz y permitir una mejor visualización del contenido. 
- ¿Cómo mi diseño se diferencia del diseño original de TikTok? ¿Es una mejora?
La mayor diferencia es la unificación de los apartados de: For You, Following, Explore y Friends. De esta manera unificando espacios y permitiendo un mejor acceso a apartados como la creación de contenido y comunicación.  
Es una mejora, por facilitar el acceso a los espacios de creación y comunicación, además de simplificar los espacios para consumir contenido.
